# Fontes de dados industriais

Catálogo de fontes abertas de dados para a indústria, com a licença de cada uma resumida e busca por tema, tipo e licença.

**Acesse:** https://projetoindustrial.github.io/fontes-industriais/

- A página só aponta para os sites originais; não hospeda nem copia os dados.
- A licença exibida é um resumo e pode estar desatualizada: confirme sempre na fonte antes de reutilizar.
- Entram apenas fontes marcadas como abertas e confirmadas na curadoria.
- Projeto independente, sem vínculo com as organizações citadas.
